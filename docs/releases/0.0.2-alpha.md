**Second Claudhar alpha: fixes from the first Thor test.** A test build, not a finished
emulator.

0.0.1-alpha kept its promises on the Thor (no compile waits, no skipped draws), but Dark
Moon slowed down badly whenever new shaders were needed, crashed soon after its opening
cutscene began, and briefly flashed what looked like later scenes. This alpha addresses
the slowdowns and makes the next crash diagnosable. Details:
[Phase 1](https://github.com/RegiRex/claudhar/blob/0.0.2-alpha/docs/PHASE1_UBERSHADER.md).

### What changed

- **GPU-vertex draws stay on the GPU while their shaders compile.** In 0.0.1-alpha, 97% of
  Dark Moon's first draws had their vertices shaded on the CPU, which is far too slow for
  that game. Such a draw now uses its own vertex shader with the fragment ubershader, which
  needs only one compile per vertex shader. The CPU takes over only for the moment that
  compile takes.
- **Background compiles yield to the game.** Specialized shaders compile at low thread
  priority, so they no longer slow the emulation thread down on a shared core.
- **The log survives a crash.** It was written to the file only at errors, so the Dark Moon
  log stopped 14 seconds into the game. It is now kept current.
- **Timing in the log.** Every 10 seconds a `Claudhar timing:` line follows the
  `Claudhar shading:` line: frames, the slowest one, how many took over 50 ms, and what the
  emulation thread spent its time on.
- **A latent crash fixed** when the system leaves an applet while shaders are still
  compiling. It is not known to be the Dark Moon crash.

### Install

Download `claudhar-0.0.2-alpha-arm64.apk` below and install it over 0.0.1-alpha. It is a
separate app next to Azahar and Uberhar.

### What to test

- **The Dark Moon opening, cold.** Reset File 1 and delete Dark Moon's shader cache (long
  press the game → Delete Shader Cache), then play through the opening cutscene. Note any
  slowdowns, pauses or flashes and roughly when they happened.
- **The log**, from Options → Share log, after the run. After a crash, also send
  `log/claudhar_crash.txt` from the data folder if Claudhar offered a crash report on the
  next launch.
- **The flashes.** If stock Azahar is installed, the same scene there shows whether
  Claudhar causes them.

### Known limits

- Draws shaded by the ubershader cost the GPU 7–9 times as much per pixel as specialized
  ones until those are compiled. That is expected to be fine at 2x and is not yet measured
  at 4x.
- The Dark Moon crash and the flashes are not explained yet.
- The multi-core core and the new renderer are later phases.
