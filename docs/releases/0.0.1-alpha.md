**First Claudhar alpha.** A test build, not a finished emulator.

Claudhar is Azahar 2126.2 being rebuilt around multi-core CPUs, with no shader
compilation pauses and no skipped draws. This alpha is Phase 1: Azahar's Vulkan renderer
with zero-pause shading. Whenever a shader is still compiling, a fragment ubershader draws
in its place, and the compiled shader takes over when it is ready. Nothing waits and no
draw is dropped. Details: [Phase 1](https://github.com/RegiRex/claudhar/blob/main/docs/PHASE1_UBERSHADER.md).

### Install

Download `claudhar-0.0.1-alpha-arm64.apk` below and install it on a 64-bit ARM Android
device running Android 10 or newer. It installs as a separate app next to Azahar and
Uberhar. If an earlier Claudhar test build is installed and Android refuses, uninstall it
first.

### What to test

- **Cold first runs.** Delete the `shaders` folder in Claudhar's data folder, then play a
  game you know. There should be no shader hitches. The first launch spends a moment on
  the loading screen preparing the ubershader.
- **The log.** Every few seconds the log (Options → Share log) has a `Claudhar shading:`
  line. `compile_waits` and `skipped` must be 0.

### Known limits

- Tested on a host CPU Vulkan driver against Azahar's shaders (8,000 configurations, all
  matching), not yet on a phone. Speed against stock Azahar is not measured yet.
- Azahar's "asynchronous shader compilation" setting has no effect on Vulkan.
- The AddSigned texture combiner now subtracts 128/255 instead of 0.5, as Azahar's
  software renderer does; some colors can differ by one step from Azahar.
- The multi-core core and the new renderer are later phases.
