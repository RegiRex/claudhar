**Fourth Claudhar alpha: a GPU driver per game.** A test build, not a finished emulator.

### What changed

- **A GPU driver for each game.** In a game's Per-Application Settings, under Graphics, the
  new GPU driver entry picks the driver that game uses: the global one from the GPU Driver
  Manager, the system driver, or any driver in your gpu_drivers folder (import drivers with
  the Driver Manager first). The driver is loaded when the game starts, so a change applies
  at the next launch, and the entry is greyed out while a game is running. A game that has
  no choice uses the global driver as before. If a chosen driver cannot be loaded, the game
  uses the global one and says so. Choices are kept in `config/drivers.ini` in the user
  folder and are cleared with the game's other per-application settings, or all of them by
  resetting all settings. Adapted from the Uberhar build's per-game driver selection.
- **One ubershader cache per driver,** so moving between games with different drivers does
  not prepare the ubershader again each time.
- Everything in [0.0.3-alpha](https://github.com/RegiRex/claudhar/releases/tag/0.0.3-alpha):
  per-game settings, crash diagnostics and the new timing line.

### Install

Download `claudhar-0.0.4-alpha-arm64.apk` below and install it over 0.0.3-alpha. Settings
carry over.

### What to test

- Give one game a driver other than the global one and start it. The log should show
  `[GameDrivers] <title ID>: driver <name>, loaded custom` and `Claudhar: GPU driver loaded:`.
- Then start a game that uses the global driver, and switch between the two a few times in
  one session. The driver is swapped inside the running app, which is where a problem would
  show.

### Known limits

- The limits of 0.0.3-alpha still apply.
