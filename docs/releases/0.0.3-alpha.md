**Third Claudhar alpha: per-game settings and crash diagnostics.** A test build, not a
finished emulator.

### What changed

- **Per-game settings**, ported from Azahar 2127.0 Alpha 4
  ([azahar-emu/azahar#1856](https://github.com/azahar-emu/azahar/pull/1856) and
  [#2698](https://github.com/azahar-emu/azahar/pull/2698)). Long-press a game and choose
  Per-Application Settings, or open them from the in-game menu. A game starts with the
  global settings; whatever you change there applies to that game only and is marked as
  customized, and long-pressing a customized setting returns it to the global value. This
  covers the settings screens (graphics API, resolution, shaders, frame limit, layout, audio
  and so on) but not the custom GPU driver, which Azahar loads once for the whole app.
  Upstream's fixes for relaunching or closing a game started from a home-screen shortcut
  come with it. Details: [ports from newer Azahar](https://github.com/RegiRex/claudhar/blob/0.0.3-alpha/docs/AZAHAR_PORTS.md).
- **Crash diagnostics.** The Xenoblade crash at 4x was the GPU driver refusing a
  submission, which Azahar does not handle. Claudhar now logs such a failure with the GPU
  memory in use, waits for the GPU to finish its earlier work and submits once more, which
  may avoid the crash. A `Claudhar memory:` line gives the GPU memory in use every 10
  seconds. Crash reports include the end of the game's log and are kept one file per crash
  (`log/claudhar_crash_<date>.txt`, the newest five).
- **A better timing line.** It now gives the speed in percent and the slowest whole second,
  leaves out time spent paused, and counts pipeline cache lookups correctly. Details:
  [Phase 1](https://github.com/RegiRex/claudhar/blob/0.0.3-alpha/docs/PHASE1_UBERSHADER.md#counters).

### Install

Download `claudhar-0.0.3-alpha-arm64.apk` below and install it over 0.0.2-alpha. Your
global settings carry over.

### What to test

- **Per-game settings.** Give two games different settings (resolution, for example) and
  check that each game uses its own and that other games keep the global ones.
- **Xenoblade at 4x**, to see whether the crash comes back and what the `Claudhar memory:`
  lines show before it. If it crashes, share the crash report Claudhar offers on the next
  launch.
- **Anything else you play**, with turbo as before, plus the log.

### Known limits

- Per-game settings are new upstream code, released in an Azahar alpha.
- The custom GPU driver cannot be chosen per game.
- Xenoblade's slowdowns at 4x are not addressed; they come from somewhere other than
  shader compiling, most likely GPU load.
- The multi-core core and the new renderer are later phases.
